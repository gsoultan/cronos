# Provider logos

These are not cronos's, and this repository's licences do not cover them. They
are here because each provider's terms require its logo on a map drawn from its
tiles, and a map that leaves one out puts the customer embedding it in breach.

| File | Whose | From |
| :--- | :--- | :--- |
| `google-maps-light-outline.svg` | Google LLC | `GoogleMaps_Logo_WithLightOutline.svg` in Google's [Map Tiles API attribution kit](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip), per the [Map Tiles API policies](https://developers.google.com/maps/documentation/tile/policies) |
| `google-maps-dark-outline.svg` | Google LLC | `GoogleMaps_Logo_WithDarkOutline.svg`, same kit |
| `mapbox.svg` | Mapbox, Inc. | The wordmark Mapbox GL JS draws (`.mapboxgl-ctrl-logo` in `mapbox-gl.css` v3.15.0), per [Mapbox's attribution guide](https://docs.mapbox.com/help/getting-started/attribution/) |

Minified — the XML prolog, comments and editor ids removed, and the Google path
data's whitespace collapsed. Nothing drawn was changed, and neither provider
allows a restyled logo, so re-take them from the source rather than editing
them here.
